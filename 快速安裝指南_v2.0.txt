台灣高鐵半自動訂位 PWA v2.0｜完整安裝指南

【A. GitHub Pages】
1. 建立 Repository，例如 thsr-quick-booking。
2. 解壓縮本 ZIP。
3. 將 ZIP 內全部檔案上傳 Repository 根目錄。
4. GitHub → Settings → Pages。
5. Branch：main；Folder：/(root)。
6. Save，等待 Pages 網址。

【B. 安裝到手機】
Android：
Chrome 開 GitHub Pages → ⋮ → 安裝應用程式／加到主畫面。

iPhone：
Safari 開 GitHub Pages → 分享 → 加入主畫面。

【C. 第一次建立行程】
1. 選起訖站。
2. 選去程 / 回程。
3. 設票種人數。
4. 設助手模式。
5. 設選車規則。
6. 儲存。
7. 設為「主攻行程」。

【D. 身分證】
可選：
- 不保存
- 本次暫存
- AES-GCM 加密保存

帶入官網可選：
- 不帶入
- 執行助手時詢問（建議）
- 自動預填

【E. 安裝訂位助手書籤】
1. PWA →「複製 v2 訂位助手」。
2. 瀏覽器建立一個普通書籤。
3. 名稱：高鐵訂位助手。
4. 編輯該書籤 URL，全部刪除後貼上 javascript: 開頭內容。
5. 行程規則變更後，重新複製助手並更新一次書籤 URL。

【F. 實際訂位】
1. 開 PWA。
2. 檢查主攻行程。
3. 按「極速啟動：準備助手＋開官網」。
4. 官方網站開啟後執行「高鐵訂位助手」書籤。
5. 助手依設定嘗試：
   填表 → 查詢 → 選車。
6. 驗證碼、最終確認、付款前會停止。
7. 您本人核對並完成官方流程。

【G. 官網改版排錯】
PWA →「複製官網診斷工具」→ 在失效頁面執行 → 把結果貼回 ChatGPT。
