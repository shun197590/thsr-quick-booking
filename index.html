未設定

🚄 開啟官方訂票
使用方式：先在 PWA 設定主攻行程 → 複製 v2 訂位助手 → 將它設成 Safari／Chrome 書籤 → 開啟高鐵官網後執行書籤。若官網換頁造成腳本停止，可在下一頁再按一次同一個書籤，助手會從官網 sessionStorage 讀取本次設定繼續。
官網頁面結構可能更新，因此本版採「偵測不到就停止」而非強行點擊。驗證碼、簡訊驗證、優惠資格確認、最終訂位確認及付款一律不自動處理。 若官網改版造成欄位辨識失敗，可執行「官網診斷工具」，把診斷文字貼回 ChatGPT，再做精準 selector 更新。

🔔 開賣提醒與搶票模式

純 GitHub Pages PWA 在完全關閉後無法保證背景 JavaScript 仍準時執行，所以「加入開賣提醒到手機行事曆」是關閉 PWA 後較可靠的備援。

🔒 穩定版資料原則

身分證採獨立安全模式，可選不保存、本次暫存或本機加密保存；信用卡號與安全碼仍不提供保存。本工具不破解驗證機制、不自動付款、不自動按最後確認送出；v2.0 自動化最多到填表、查詢與選車輔助，最後交易仍由您在台灣高鐵官方系統確認。

本工具為個人行程準備與官方訂票捷徑，非台灣高鐵官方 App。官方規則、票價、餘票、優惠與實際訂位結果，以台灣高鐵系統顯示為準。
